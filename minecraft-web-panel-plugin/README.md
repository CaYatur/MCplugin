# Minecraft Web Panel Plugin

## Overview
The Minecraft Web Panel Plugin is a powerful tool that allows server administrators to manage their Minecraft server through a web-based control panel. This plugin provides real-time interaction with the server, enabling the sending of messages to the game chat, executing commands in the console, and listing all players currently online with their names and player heads.

## Features
- **Web Control Panel**: Access the server management interface through a web browser.
- **Real-time Player List**: View all players currently online along with their player heads.
- **Chat Messaging**: Send messages directly to the Minecraft chat from the web panel.
- **Command Execution**: Enter and execute commands in the Minecraft console via the web interface.

## Installation
1. Download the latest version of the Minecraft Web Panel Plugin.
2. Place the `minecraft-web-panel-plugin.jar` file into the `plugins` folder of your Minecraft server.
3. Restart the server to enable the plugin.
4. Access the web control panel by navigating to `http://<your-server-ip>:<port>` in your web browser (default port can be configured in `config.yml`).

## Usage
- Use the web panel to manage your server easily.
- Send messages to the chat or execute commands directly from the interface.
- Monitor player activity in real-time.

## Configuration
- The plugin's settings can be customized in the `config.yml` file located in the plugin's directory.
- Adjust the server port and other options as needed.
